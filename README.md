# LibraryInformationSystem — учебный командный WPF-проект

Каталог книг, читатели, выдачи и проверка целостности. Исходник сохранён и расширен.

Ветки: `main`, `feature/books`, `feature/readers`, `feature/loans`.

Инструкции по всем 7 пунктам и скриншотам: `docs/TEAM_AND_GIT.md`.

Запуск в Windows: `dotnet run --project src/LibraryInformationSystem/LibraryInformationSystem.csproj` (SDK .NET 8).
