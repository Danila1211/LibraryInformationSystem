# LibraryInformationSystem

Учебная информационная система библиотеки на WPF.

## Структура
- `src/LibraryInformationSystem/` — исходный код WPF.
- `tests/` — каталог тестов.
- `docs/` — документация.
- `resources/` — ресурсы.
- `.gitignore` — исключения Git.

## Запуск
Откройте `LibraryInformationSystem.sln` в Visual Studio 2022 с поддержкой .NET 8 и WPF.
